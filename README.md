# Table Talk Trivia

A short trivia game for families sharing one screen at a Thanksgiving table.

## Play it

Web address: [Add your game’s web address here]

You need a phone or computer and enough players for 2–3 teams.

## How to play

1. Choose two or three teams. Each team is labeled Player 1, Player 2, or Player 3.
2. Take turns picking Judaism, sports, pop culture, or history. Six of the eight sports questions focus on women’s sports.
3. Type an answer within 30 seconds. Tap **Check answer** or press Enter.
4. A correct answer earns one point. Minor spelling slips count. If an answer is wrong, try again before time runs out.
5. Pass to reveal the answer. If the game rejects an equivalent answer, the table can agree to count it.
6. After five turns per team, the highest score wins. Tied teams share the win. A game takes about 5–10 minutes.
